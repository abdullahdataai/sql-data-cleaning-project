# SQL Data Cleaning Project

## Overview
This project demonstrates real-world SQL data cleaning using SQL Server.

## Tasks Performed
- Cleaned inconsistent order status values
- Standardized product names
- Fixed quantity data types
- Standardized customer names
- Detected and removed duplicate records
- Created final cleaned dataset

## Tools Used
- SQL Server Management Studio (SSMS)
- SQL Server
- GitHub

## Skills
- SQL Data Cleaning
- CASE Statements
- TRY_CAST
- Window Functions
- ROW_NUMBER()

## Result
A clean dataset ready for data analysis and reporting.
